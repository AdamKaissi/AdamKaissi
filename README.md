## Featured projects

### 🏙️ [Dubai Real Estate Market Analytics](https://github.com/AdamKaissi/dubai-real-estate-analytics)
Cleaned 898,413 raw Dubai Land Department transactions into 348,789 residential sales (2019 to 2026) with a logged Python pipeline, loaded them into a PostgreSQL star schema (Docker), and modeled price per sqm with a regression (R² 0.594). Off-plan units are priced about 38% higher, and a 3-page Power BI dashboard covers the market, areas and price drivers.
`Python` `PostgreSQL` `SQL` `Regression` `Power BI` `Docker`
